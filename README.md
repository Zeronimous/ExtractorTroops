# JSON Text Extraction and Injection Scripts

This project contains two Python scripts for extracting text from `.json` files (specifically `Troops.json` for now) into `.tsv` files for manual translation, and then injecting these translations back into new JSON files.

## Project Structure

-   `jsonfiles/`: Directory to place your original `.json` files.
    -   A sample `Troops.json` is provided.
-   `tsvfiles/`: Directory where the extraction script will save the `.tsv` files containing extracted text.
    -   This directory will also contain `.map.json` files (e.g., `Troops.json.map.json`). These files are automatically generated by `extract_text.py` and are crucial for `inject_text.py` to correctly place translations. **Do not edit these `.map.json` files.**
-   `fixedjsonfiles/`: Directory where the injection script will save the new `.json` files with translated text.
-   `extract_text.py`: Script to extract text from JSON to TSV and generate corresponding `.map.json` files.
-   `inject_text.py`: Script to inject translated text (read from the `Text` column in the TSV) using the `.map.json` files, into new JSON files.

## Prerequisites

-   Python 3.x
-   The `jsonpath-ng` library. You can install it using pip:
    ```bash
    pip install jsonpath-ng
    ```

## Workflow

### 1. Place your JSON files

-   Put your `Troops.json` file(s) (or other supported JSON files as the script evolves) into the `jsonfiles/` directory.

### 2. Run the Extraction Script

-   Execute `extract_text.py` from the root of the project:
    ```bash
    python extract_text.py
    ```
-   This will generate `.tsv` files (e.g., `tsvfiles/Troops.tsv`) and associated `.map.json` files (e.g., `tsvfiles/Troops.json.map.json`) in the `tsvfiles/` directory.

### 3. Translate the Text in TSV Files

-   Open the generated `.tsv` files (e.g., `tsvfiles/Troops.tsv`) using a spreadsheet editor (like Google Sheets, Excel, LibreOffice Calc) or a text editor that handles TSV well.
-   The TSV file will have the following columns as generated by the script: `ListNum`, `Code`, `Indent`, `Text`.
-   **Directly edit the content of the `Text` column with your translations.** Replace the original text in this column with the translated version.
-   If you want to keep the original text for a specific entry (i.e., not translate it), simply leave its content in the `Text` column unchanged. If the `Text` column is empty for a row, no text will be injected for that entry.
-   Save the changes to the TSV file.

**Example `Troops.tsv` (as generated by `extract_text.py`):**

| ListNum | Code | Indent | Text              |
|---------|------|--------|-------------------|
| 1       | 101  | 1      | Colonel Squeakums |
| 2       | 102  | 1      | Yes.              |
| 3       | 102  | 1      | No.               |
| ...     | ...  | ...    | ...               |

**Example `Troops.tsv` (after you edit the `Text` column with your translations):**

| ListNum | Code | Indent | Text                |
|---------|------|--------|---------------------|
| 1       | 101  | 1      | Coronel Chirridos   |
| 2       | 102  | 1      | Sí.                 |
| 3       | 102  | 1      | No.                 |
| ...     | ...  | ...    | ...                 |

### 4. Run the Injection Script

-   Once you have edited the `Text` column in the TSV files with your translations, execute `inject_text.py` from the root of the project:
    ```bash
    python inject_text.py
    ```
-   This script will read the TSV files (taking the translations from the `Text` column) and their corresponding `.map.json` files from `tsvfiles/`. It uses the map to find the original JSON files in `jsonfiles/` and to correctly place the translated text into new JSON files created in `fixedjsonfiles/`.
-   For example, if `tsvfiles/Troops.tsv` (and its accompanying `tsvfiles/Troops.json.map.json`) contains translations in its `Text` column for `jsonfiles/Troops.json`, a new `fixedjsonfiles/Troops.json` will be created.

## Notes

-   The scripts currently have specific text extraction rules tailored for a structure like `Troops.json`.
-   Error handling is included. Warnings or error messages will be printed to the console for issues like missing files, malformed JSON/TSV/Map files, or missing expected data fields.
-   The original JSON files in `jsonfiles/` are never modified. The injection script creates new files in `fixedjsonfiles/`.
-   **Important**: Do not edit the `.map.json` files in the `tsvfiles/` directory, as they are essential for the correct operation of the `inject_text.py` script.
