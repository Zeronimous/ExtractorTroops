# JSON Text Extraction and Injection Scripts

This project contains Python scripts for extracting text from specific RPG Maker MV/MZ `.json` files (like `Troops.json` and `CommonEvents.json`) into `.tsv` files for manual translation, and then injecting these translations back into new JSON files.

## Project Structure

-   `jsonfiles/`: Directory to place your original `.json` files.
    -   Sample `Troops.json` and `CommonEvents.json` files might be provided or should be placed here by the user.
-   `tsvfiles/`: Directory where the extraction scripts will save the `.tsv` files containing extracted text and their corresponding `.map.json` files.
    -   For example, processing `Troops.json` will generate `Troops.tsv` and `Troops.json.map.json`.
    -   Processing `CommonEvents.json` will generate `CommonEvents.tsv` and `CommonEvents.json.map.json`.
    -   These `.map.json` files are automatically generated and are crucial for the injection script. **Do not edit these `.map.json` files.**
-   `fixedjsonfiles/`: Directory where the injection script will save the new `.json` files with translated text.
-   `extract_troops.py`: Script to extract text from `Troops.json` files. It expects a structure where text is found within event lists nested under a `pages` array for each troop object (i.e., `RootList[i] -> pages[j] -> list[k] -> command`).
-   `extract_commonevents.py`: Script to extract text from `CommonEvents.json` files. It expects a shallower structure where text is found within event lists directly under each common event object (i.e., `RootList[i] -> list[k] -> command`).
-   `inject_text.py`: Script to inject translated text (read from the `Text` column in a TSV) back into new JSON files, using the corresponding `.map.json` file. This script works for outputs generated by both extraction scripts.

## Prerequisites

-   Python 3.x
-   The `jsonpath-ng` library (though currently, f-strings are used for path generation in extraction, `jsonpath-ng` is used by `inject_text.py`). You can install it using pip:
    ```bash
    pip install jsonpath-ng
    ```

## Workflow

### 1. Place your JSON files

-   Place your `Troops.json` and/or `CommonEvents.json` files into the `jsonfiles/` directory.
-   Ensure the JSON files are structured as expected by the specific extraction script you intend to use (see "Note on JSON Structures" below).

### 2. Run the Appropriate Extraction Script

-   Execute the specific extraction script for the type of JSON file you want to process. Run these commands from the root of the project:

    -   **To process `Troops.json`:**
        ```bash
        python extract_troops.py
        ```
        This will generate `tsvfiles/Troops.tsv` and `tsvfiles/Troops.json.map.json`.

    -   **To process `CommonEvents.json`:**
        ```bash
        python extract_commonevents.py
        ```
        This will generate `tsvfiles/CommonEvents.tsv` and `tsvfiles/CommonEvents.json.map.json`.

### 3. Translate the Text in TSV Files

-   Open the generated `.tsv` file (e.g., `tsvfiles/Troops.tsv` or `tsvfiles/CommonEvents.tsv`) using a spreadsheet editor or a text editor.
-   The TSV file will have the columns: `ListNum`, `Code`, `Indent`, `Text`.
-   **Directly edit the content of the `Text` column with your translations.** Replace the original text with its translated version.
-   If you want to keep the original text for an entry, leave its content in the `Text` column unchanged. If the `Text` column is empty for a row, no text will be injected for that entry.
-   Save the changes to the TSV file.

**Example `filename.tsv` (e.g., `Troops.tsv` or `CommonEvents.tsv`) as generated:**

| ListNum | Code | Indent | Text              |
|---------|------|--------|-------------------|
| 1       | 101  | 0      | Some sample text  |
| 2       | 401  | 0      | Another message   |
| ...     | ...  | ...    | ...               |

**Example `filename.tsv` after you edit the `Text` column:**

| ListNum | Code | Indent | Text                |
|---------|------|--------|---------------------|
| 1       | 101  | 0      | Translated text     |
| 2       | 401  | 0      | Otro mensaje        |
| ...     | ...  | ...    | ...                 |

### 4. Run the Injection Script

-   Once you have edited the `Text` column in the relevant TSV files, execute `inject_text.py` from the root of the project:
    ```bash
    python inject_text.py
    ```
-   This script will find all `.tsv` files in the `tsvfiles/` directory, look for their corresponding `.map.json` files, and process them.
-   It uses the map to find the original JSON file (e.g., `Troops.json` or `CommonEvents.json`) in `jsonfiles/` and creates a new JSON file with the translated text in `fixedjsonfiles/`.
-   For example, if `tsvfiles/Troops.tsv` contains translations, `fixedjsonfiles/Troops.json` will be created. If `tsvfiles/CommonEvents.tsv` contains translations, `fixedjsonfiles/CommonEvents.json` will be created.

## Notes

-   **Note on JSON Structures**:
    *   `extract_troops.py` assumes `Troops.json` contains event commands in a path like: `RootList[i] -> pages[j] -> list[k] -> command`.
    *   `extract_commonevents.py` assumes `CommonEvents.json` contains event commands in a path like: `RootList[i] -> list[k] -> command`.
    Ensure your input files match the expected structure for the script you are using.
-   Error handling is included. Warnings or error messages will be printed to the console for issues like missing files, malformed JSON/TSV/Map files, or missing expected data fields.
-   The original JSON files in `jsonfiles/` are never modified. The injection script creates new files in `fixedjsonfiles/`.
-   **Important**: Do not edit the `.map.json` files in the `tsvfiles/` directory, as they are essential for the correct operation of the `inject_text.py` script.
